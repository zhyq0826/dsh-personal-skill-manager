# My skills

Open **My skills** in the DSH sidebar to find skills on this computer across DSH, Codex, Claude Code, and Cursor. Select a skill to read it and see where it came from.

## Keep a skill

Select **Favorite** to keep a community skill’s source and version in your personal library. To edit your own copy, select **Save as my skill**.

In **Sync**, choose the clients you use and select **Distribute to clients** to place the skills you maintain in their skill directories.

## Move to another computer

On the original computer, open **Sync**, save the personal library directory, Git remote, and branch, then select **Sync personal library**. On the new computer, save the local directory, remote, and branch, then select **Restore from Git** under **Restore on another computer** to recover your skills and favorites.
