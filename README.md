# 我的技能

在 DeepSeek Harness（DSH）里统一查看、收藏和维护技能，再分发到 Codex、Claude Code、Cursor 和 DSH。

技能散落在不同客户端时，很难记清放在哪里、改过哪个版本。“我的技能”把这些目录和共享目录中的技能列在一个面板里，让你查找技能、查看完整内容和各客户端的版本状态。自己编写或修改的技能放进个人库，用 Git 同步后，可以在另一台电脑上恢复。

[English](README.en.md) · [详细操作指南（英文）](PLUGIN.md) · [仓库维护指南](AGENTS.md)

## 安装

需要已安装 DSH，并能使用 `dsh` 命令。在终端运行：

```sh
dsh plugin --profile desktop add @zhyq0826/dsh-personal-skill-manager
```

安装后，在对应 DSH profile 的侧栏打开 **我的技能**。如果使用的不是 `desktop` profile，请替换命令中的 profile 名称。

## 能做什么

- **查找技能**：按名称、描述或路径搜索，按客户端筛选，查看来源、完整 `SKILL.md` 和支持文件列表。
- **维护个人技能**：创建技能，把已有技能另存为自己的版本，编辑内容，调整模型和用户的调用方式。只读来源的技能需先另存。
- **分发到客户端**：把个人技能以链接或复制方式分发到启用的客户端，查看内容是否一致以及是否存在冲突。
- **同步与换机恢复**：通过 Git 同步个人技能、技能收藏和插件收藏；在另一台电脑上取回个人库、安装来源明确的技能收藏并分发个人技能。
- **查看插件**：汇总各客户端的插件记录，收藏插件，并为所选客户端生成安装 Prompt，复制到 Agent 对话中执行。

也可以在 DSH 对话中通过 `skill_hub` 工具查看和管理技能。

## 开始使用

### 收藏技能，或维护自己的版本

打开技能详情后，按用途选择：

| 你想做什么 | 使用哪个操作 | 保存什么 |
| --- | --- | --- |
| 记住一个社区技能，方便以后重装 | 收藏 | 来源和固定提交，不复制技能包到个人库 |
| 修改一个技能，并长期维护自己的版本 | 另存为我的技能 | 将技能包保存到个人库，之后可以编辑和分发 |
| 从头编写技能 | 创建技能 | 在个人库中创建新技能 |

收藏时无法确认来源的技能仍可保留记录，但自动安装会跳过它。需要重装已收藏的技能时，在 **同步** 页面使用 **安装收藏**。

### 配置个人库并分发

1. 打开 **同步 → 个人库同步**，在仓库设置中保存个人库目录、Git 远程地址和分支。
2. 在本机客户端列表中，启用需要接收个人技能的客户端，选择链接或复制方式并保存设置。
3. 分发个人技能，检查结果。遇到不同内容时默认保留客户端版本；确认替换后，会先备份再写入。
4. 准备好共享本次修改时，点击 **同步个人库**，将个人库变更同步到 Git 远程仓库。

链接方式让客户端读取个人库原文件，下次读取即可获得已保存的更新；复制方式使用独立副本，个人技能更新后需要再次分发。

### 换一台电脑

安装插件后，在 **同步** 页面填写同一 Git 远程地址和分支，选择本机个人库目录及客户端，保存设置，再执行 **从 Git 恢复**。首次克隆请选择空目录，或选择同一远程仓库的已有检出目录。完成后检查恢复、收藏安装和分发结果，处理报告中的冲突。

## 数据与操作边界

个人库保存自有技能；其中的 `.skill-hub/` 保存技能清单、技能收藏和插件收藏。本机设置、备份和回收内容保存在 `$DSH_HOME/skill-hub/`。

- 编辑前保留原文件；删除个人技能时，将技能包移入回收目录。
- Git 同步只暂存个人技能及其库元数据，只允许快进同步。自动提交只写本地 Git，推送仍由你手动触发。
- 插件清单区分安装记录、缓存和本地目录，是否启用或成功加载需要在对应客户端确认。生成安装 Prompt 只生成文本，不会安装或启用插件。

备份位于 `$DSH_HOME/skill-hub/backups/`，回收的技能包位于 `$DSH_HOME/skill-hub/trash/`。
