# 我的技能

打开 DSH 侧栏的 **我的技能**，可以在一处查找这台电脑上 DSH、Codex、Claude Code 和 Cursor 的技能，查看内容和来源。

## 留下想用的技能

想记住某个社区技能，点击 **收藏**，把来源和版本记入个人库。想按自己的需要修改它，点击 **另存为我的技能**，再编辑副本。

在 **同步** 中选好要使用的客户端，点击 **分发到客户端**，就能把自己维护的技能放到对应客户端的技能目录。

## 换台电脑继续用

在原电脑的 **同步** 页面设置个人库目录、Git 远程仓库和分支，保存设置后点击 **同步个人库**。在新电脑上选择本地目录，填入同一个仓库和分支，保存设置后在 **换机恢复** 中点击 **从 Git 恢复**，即可取回个人技能和收藏记录。
