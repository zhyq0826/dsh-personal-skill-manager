# 我的技能

打开 DSH 侧栏的“我的技能”，可以搜索这台电脑上 DSH、Codex、Claude Code 和 Cursor 的技能。选中一个技能，就能查看它的来源和完整的 `SKILL.md`。

## 收藏和修改技能

遇到想留着的社区技能，点星标就能在“我收藏的”里找到它。个人库会保存收藏记录，包括能识别的来源和版本。想改成自己的版本，点“另存为我的技能”，再编辑副本。

## 在本机使用

打开“同步”里的“在本机使用”，启用需要的客户端并保存设置。可以在这里批量分发个人技能，也可以打开某个技能，在客户端名称旁点“分发到 DSH”等按钮，单独分发这一个。

## 换台电脑继续用

1. 在原电脑上打开“同步”，在“个人库同步”的“仓库设置”里填好个人库目录、Git 远程仓库和分支。保存设置后，点“同步个人库”。
2. 在新电脑上选择本地目录，填入同一个 Git 仓库和分支。保存设置后，打开“换机恢复”，点“从 Git 恢复”取回个人技能和收藏记录。
